# Shopping-Agent
A shopping agent that searches product by keyword, get ratings of products, checkout, and search by image. The search can also be based on history context.

# Run the project
1. Activate venv: <q>source .venv/bin/activate</q> </br>
2. Install the required packages</br>
3. Command to run the shopping agent application: <q>python -m streamlit run app.py</q>
